RedBus 2+1 Sleeper & Privacy Architecture

1. Standard 2+1 Sleeper Layout:

  • Single Berths (Left): Solitary Window Berths with extra privacy. Carries a +₹150 premium.
  • Double Berths (Right): Outer Window berths carry +₹100 premium; Inner Aisle berths are base fare.
  • 2 Decks: Lower Deck (L1 to L12) and Upper Deck (U1 to U12).

2. Passenger Privacy Protection:

Ordinary passengers can pick empty seats and book their journeys without ever seeing another traveler's identity. Passenger names, phone numbers and emails stay inside SQL Server (RedBusDB) and are never exposed by the public app.

3. SQL Server (SSMS):

All records are stored in table dbo.Travelers on database RedBusDB.
